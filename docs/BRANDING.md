# Lovely identity

The owner supplied the Lovely Dress Rental & Tailoring logo and requested its colors throughout the existing site. The supplied image, not an invented replacement, is used as a metadata-free 640×640 WebP in `public/brand/lovely-logo.webp`; the app icon is a 64×64 PNG. The original chat image is not included in the public asset directory.

Palette: dark pink #a61d55 for readable primary controls; light pink #fce5ee and #fff9fb for surfaces; #25171e and white for text/surfaces; #27131e for the staff-preview sidebar. Pink status/control variants replace the old green palette. Strong red and explicit text distinguish important collision/errors. Dress photograph colors are preserved.

Header/footer, catalogue, login, protected shared frame, preview navigation/dashboard, forms, calendar, categories, alerts and favicon use this identity. The prototype notice remains visible and non-operational, now within the pink/black palette. This is a branding update to the same project, not a separate design mockup.
